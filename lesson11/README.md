# Lesson 11: Мокування в TypeScript для Unit-тестів

У цій папці зібрано 2 навчальні проєкти, де ми розглядаємо підходи до мокування залежностей у unit-тестах на TypeScript.

## Що покриваємо

- Ізоляцію бізнес-логіки від зовнішніх залежностей.
- Мокування сервісів, репозиторіїв та утиліт.
- Перевірку викликів, аргументів та очікуваних результатів.
- Порівняння підходів у `Mocha + Sinon` та `Vitest`.

## Проєкти

### 1) mocha-sinon

Демонструє класичний підхід до мокування через Sinon у тестах на Mocha.

- Встановлення:

```bash
cd mocha-sinon
npm install
```

- Запуск тестів:

```bash
npm test
```

- Type check + lint:

```bash
npm run run
```

### 2) vitest-mock

Демонструє вбудовані можливості мокування у Vitest.

- Встановлення:

```bash
cd vitest-mock
npm install
```

- Запуск тестів:

```bash
npm test
```

- Type check + lint:

```bash
npm run run
```

## Рекомендований порядок проходження

1. Почати з `mocha-sinon`, щоб зрозуміти базову механіку моків/стабів/спаїв.
2. Перейти до `vitest-mock`, щоб порівняти API та швидкість роботи.
3. Відпрацювати однакові сценарії в обох підходах і зафіксувати різницю.
