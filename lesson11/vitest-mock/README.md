# Vitest Mocking (TypeScript)

Цей проєкт демонструє unit-тестування в TypeScript з використанням вбудованого мокування у Vitest.

## Мета

- Вивчити підхід до моків через API Vitest.
- Швидко перевіряти ізольовану логіку модулів.
- Переконуватись, що залежності викликаються правильно.

## Структура

- `src/` - код застосунку та приклади.
- `src/hooks/vitest-global-setup.ts` - глобальний setup для тестів.
- `tests/` - тестові сценарії Vitest.
- `vitest.config.ts` - конфігурація запуску тестів.

## Встановлення

```bash
npm install
```

## Запуск тестів

```bash
npm test
```

## Перевірка типів і лінтинг

```bash
npm run run
```

## Що варто відпрацювати

1. Використати `vi.mock` для підміни зовнішньої залежності.
2. Перевірити виклики через `toHaveBeenCalledWith` і `toHaveBeenCalledTimes`.
3. Порівняти читабельність тестів із аналогічними кейсами в Mocha + Sinon.
