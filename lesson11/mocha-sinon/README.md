# Mocha + Sinon (TypeScript)

Цей проєкт показує, як писати unit-тести з мокуванням залежностей у TypeScript, використовуючи Mocha та Sinon.

## Мета

- Навчитись ізолювати модулі для unit-тестування.
- Практикувати моки, стаби та спаї для контролю поведінки залежностей.
- Перевіряти виклики методів, аргументи та кількість звернень.

## Структура

- `src/` - основний код і приклади сервісів.
- `tests/` - тестові сценарії Mocha.
- `hooks/global-hooks.ts` - глобальні хуки життєвого циклу тестів.

## Встановлення

```bash
npm install
```

## Запуск тестів

```bash
npm test
```

## Перевірка типів і лінтинг

```bash
npm run run
```

## Що варто відпрацювати

1. Замокати методи сервісу даних і перевірити, що бізнес-логіка не звертається до реальної БД.
2. Перевірити, що потрібні залежності викликаються з правильними аргументами.
3. Порівняти поведінку `stub` і `spy` на одному й тому самому сценарії.
